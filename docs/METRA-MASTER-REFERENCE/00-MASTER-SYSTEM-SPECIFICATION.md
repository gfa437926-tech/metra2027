# 00 — المواصفات العامة للنظام

**METRA 2027** — منصة إدارة البيانات الجوية والرصد والتحليل.

## المبادئ
1. لا فقدان وظائف قديمة دون توثيق قرار.
2. لا وظائف علمية وهمية تُعرض كبيانات حقيقية.
3. الصلاحيات على الخادم وليس الواجهة فقط.
4. تدقيق لكل عملية حساسة.
5. Fail-closed للأرشيف العلمي حتى جاهزية العقد.
6. مصدر الحقيقة للواجهات القديمة: metra-old.
7. مصدر الحقيقة للتنفيذ: هذا المرجع + فروع metra2027.
