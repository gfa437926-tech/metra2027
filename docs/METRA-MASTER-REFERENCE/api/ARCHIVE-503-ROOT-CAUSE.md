# Archive API 503 — السبب الحقيقي

## ما وُجد في الكود
- العميل يرمي `MetraApiException(503, 'api_not_configured')` إذا لم تُهيأ الـ API.
- الخادم يعيد **503** عند: خدمة غير مهيأة، فشل تخزين/قراءة، عدم جاهزية readiness، عدم توفر خدمة الرصد/التفويض.
- لا يظهر على فرع التوثيق محرك `observation-archive` جاهز للإنتاج.

## التفسير
**503 هنا سلوك fail-closed مقصود** إلى أن يُعتمد عقد الأرشيف (قرار U-09)، وليس «عطل عابر» يُصلح بإرجاع بيانات وهمية.

## ماذا لم يُفعل
- لم يُفتح الأرشيف.
- لم تُغيَّر قاعدة البيانات.
- لم تُضف استجابة وهمية 200.

## ماذا يلزم للافتتاح لاحقاً
اعتماد U-09 + تنفيذ endpoint/RPC قراءة معتمدة + اختبارات تفويض محطة + عدم كسر immutability.
