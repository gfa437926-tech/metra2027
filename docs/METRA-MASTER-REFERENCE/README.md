## الغرض

هذا المجلد هو **المصدر الرسمي المعتمد** لتنفيذ تطبيق METRA 2027. يجمع:

- جميع واجهات ووظائف وحقول وقواعد النظام القديم (METRA Old).
- جميع الواجهات والمواصفات والوظائف الجديدة في METRA 2027 (Flutter + .NET).
- مصفوفات التتبع والمقارنة دون حذف أي وظيفة قديمة ودون إلغاء أي وظيفة جديدة.
- قواعد التحقق، الوحدات، الأدوار، مسارات العمل، الأمن، التقارير، AI، والاختبارات.

**لا يُسمح بالتخمين العلمي.** أي حد أو وحدة أو رمز غير موثق في المصدر يُسجَّل صراحةً كـ «غير محدد في المصدر» أو «يحتاج اعتماداً علمياً».
