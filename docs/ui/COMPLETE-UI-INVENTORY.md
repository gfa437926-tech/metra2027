## مفردات الحالة

| الحالة | المعنى |
|---|---|
| مكتملة تصميمياً ووظيفياً | واجهة حقيقية + مسار خادمي معتمد يعمل ضمن العقود الحالية (مع احتمال نواقص UX طفيفة) |

| غير قابلة للتحقق | تحتاج تشغيل يدوي/جهاز/CI غير متوفر هنا |

## 8) ملخص التصميم (عرضي)

| المحور | التقييم من الكود |
|---|---|
| العربية / RTL | مُطبَّق في الدخول والتنقل والرسائل الأساسية (`Directionality` / نصوص عربية) |
| ألوان/بطاقات | نمط متكرر (أزرق METRA، بطاقات تنبيه `#FFF7E8`) — **لا إثبات** تطابق 100% مع أرشيف التصميم المرجعي (RAR غير مفكوك في المستودع) |
| قائمة جانبية واحدة | `MetraAdaptiveNavigation` + تصفية وجهات — لا تكرار shell ثانٍ ظاهر |
| تحميل / فراغ / خطأ | موجودة في الرصد المتصل، الإدارة، التنبؤ، الدليل؛ ضعيفة أو ثابتة في Placeholder |
| تجاوب هاتف/ويب | Adaptive nav؛ النماذج `embedded` في تبويبات — يحتاج تحقق جهاز |
| أزرار بلا فعل | CLIMATOL، أجزاء AI/تقارير/عمليات — متعمّد مع إشعار |

## 9) ملخص الوظائف الحرجة

| الوظيفة | الوضع |
|---|---|
| دخول / خروج / استعادة بريد | دخول+خروج+طلب استعادة؛ لا تسجيل جديد |
| تنقل بصلاحيات | نعم (Access Context fail-closed) |
| إرسال hourly/daily/phenomenon | مربوط API |
| النماذج السبعة | تحقق محلي فقط |
| مراجعة/اعتماد | مربوط ضمن صلاحيات |
| بحث محطات | موجود جزئياً |
| CLIMATOL / AI / تقارير | واجهة فقط |
| منع تكرار الإرسال | في نماذج الرصد المتصلة (اعتماد كود؛ تشغيل هنا غير متاح) |

## 10) إحصاءات الجرد

| فئة | العدد (تقريبي) |
|---|---:|
| شاشات/وحدات UI مميزة مُجردة أعلاه | **~35** (بما فيها غير الموجودة المطلوبة) |
| موجودة في الكود (شاشات/تبويبات رئيسية) | **~27** |
| مكتملة وظيفياً ضمن العقد الحالي (رصد متصل + رفض صلاحية + أجزاء ثابتة) | **~5–7** |
| مكتملة جزئياً | **~12–14** |
| Placeholder | **~5** (CLIMATOL، AI×3 منطقيات، عمليات، تقارير — تُحسب كوحدات) |
| غير موجودة ومطلوبة تشغيلياً | **~8** |
| مكتملة تصميمياً بلا خادم (كتالوج×7 + شاشة كتالوج) | **8** |

**نسبة اكتمال الواجهات (تقدير مركّب):**  
- وجود هيكل/شاشة: **~75%** من القائمة التشغيلية المتوقعة  
- اكتمال وظيفي للإنتاج: **~40–48%**  
- وزن الرصد المتصل يرفع الجاهزية التشغيلية الأساسية فوق الواجهات الشكلية (CLIMATOL/AI).

> لا تُعلن نسبة «100% واجهات» قبل إغلاق Placeholders والربط الخادمي للنماذج المعتمدة وتدفقات التسجيل.
