## تعريف «تم إغلاق النواقص»

- لا تبويب إنتاجي يدّعي الحفظ بلا عقد.  
- hourly/daily/phenomenon + الأنواع المعتمدة مربوطة ومختبَرة.  
- Placeholders إما مُنفَّذة بعقد أو مخفية عن أدوار لا تحتاجها.  
- تسجيل/حالة حساب مفهومة للمستخدم.  
- اختبارات ويدجت/وحدة خضراء في CI (تشغيل فعلي).
