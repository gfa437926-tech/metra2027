- **الصلاحيات:** واجهة Flutter تعرض زري الاعتماد والإرجاع دون تحميل صلاحيات فعالة؛ Backend يفرض `observation.approve` أو `observation.return_for_correction` لكل قرار، ويقبل queue عند توفر review أو approve أو return. المصفوفة الأولية تمنح approve لرئيس التدقيق وتمنح review/return لرئيس المحطة ومدقق المحطة. لا يوجد حالياً عقد موثوق في Flutter لفلترة الأزرار حسب الصلاحيات، لذا يبقى المنع النهائي على الخادم.
