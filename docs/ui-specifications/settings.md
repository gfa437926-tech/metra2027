# مواصفات الإعدادات والحساب

## الهدف
توفير مكان موحد لإعدادات الحساب والعرض واللغة والمساعدة والخروج وروابط التدقيق المرتبطة بالمستخدم.

## عناصر الواجهة
- بيانات الحساب غير الحساسة.
- المحطة الحالية ونطاق الوصول للقراءة.
- تفضيل اللغة/العرض إذا كان مدعوماً.
- الوضع الفاتح/الداكن إذا كان مدعوماً.
- رابط المساعدة/حول التطبيق.
- تسجيل الخروج.
- رابط سجل تدقيق المحطة عند توفر محطة وسماح الخادم.

## الصلاحيات
لا تسمح الإعدادات بتغيير الدور أو نطاق المحطة أو الصلاحيات مباشرة. التغييرات الإدارية تمر عبر واجهة مدير النظام وخدمة مفوضة.

## Flutter
`mobile/metra_mobile/lib/features/home/metra_home.dart` (قسم `_SettingsPage` حسب تتبع المتطلبات)؛ التنقل المشترك `core/widgets/metra_adaptive_navigation.dart`.

## الاختبارات
RTL؛ تغيير اللغة/المظهر إن كان مدعوماً؛ انتهاء الجلسة؛ الخروج؛ روابط غير مخولة؛ عدم تكرار القائمة الجانبية.

## الحالة
التتبع الحالي يصف الإعدادات بأنها موسعة ضمن صفحة Home؛ تحقق من تفاصيل التنفيذ الفعلية قبل إعلان اكتمال كل عنصر.
