# مواصفات المصادقة والتسجيل واستعادة الحساب

## الهدف
تغطية دخول المستخدم، طلب إنشاء حساب، مراجعة الطلب، استعادة كلمة المرور، الخروج وإدارة الجلسة.

## الشاشات
1. تسجيل الدخول: معرف الدخول/البريد أو وسيلة الهوية التي يعتمدها مزود الهوية، كلمة المرور، إظهار/إخفاء، حالة الخطأ، استعادة كلمة المرور.
2. طلب التسجيل: بيانات الهوية الأساسية ووسيلة التواصل والمحطة المطلوبة والدور المطلوب وفق النموذج المعتمد. الطلب لا يمنح وصولاً تلقائياً.
3. انتظار الموافقة: حالة الطلب ورسالة الخطوة التالية دون كشف تفاصيل إدارية.
4. استعادة كلمة المرور: تدفق مزود الهوية فقط؛ لا ترسل كلمة مرور جديدة عبر البريد أو تخزنها محلياً.
5. الجلسة: انتهاء الجلسة، الخروج، تحديث الرمز، ومنع الوصول بعد إلغاء الحساب.

## الصلاحيات
- التسجيل لا يختار امتيازات فعالة ذاتياً.
- مدير النظام/المراجع المخول يعتمد الطلب وفق سياسة موثقة.
- ربط المحطة والدور مصدره الخادم.
- لا تعرض أسرار الجلسة أو الرموز في السجلات.

## التحقق
اختبارات نجاح/فشل الدخول، حساب غير مفعل، طلب قيد الانتظار، انتهاء الرمز، استعادة الحساب، إلغاء الصلاحية، وروابط deep-link المحمية.

## الحالة
ملف المصادقة وواجهة إدارة المستخدمين موجودان؛ اكتمال التسجيل والموافقة واستعادة كلمة المرور يجب التحقق منه عبر مزود الهوية وstaging. لا تضع علامة إنتاجي قبل اختبار end-to-end.
