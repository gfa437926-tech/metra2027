# مركز التنبؤ الجوي — Weather Forecasting Center

**الفرع:** `work/legacy-ui-migration-audit`  
**النوع:** وحدة اطلاع فقط (لا تعديل/اعتماد سجلات)

## ما نُفّذ

### Backend
- `GET /api/v1/forecasting/stations` — دليل المحطات + ملاحظة أن لقطة الرصد غير متاحة بعد
- `GET /api/v1/forecasting/stations/{id}` — ملف محطة من الكتالوج
- `POST /api/v1/forecasting/compare` — مقارنة 2–12 محطة: مسافة Haversine وفرق الارتفاع عند توفر البيانات
- `GeoDistance` — حساب جغرافي بدون اختراع إحداثيات

المصادقة: سياسة التطبيق الافتراضية (JWT). لا صلاحية تعديل من هذه المسارات.

### Angular
- مسار `/forecasting` + رابط في القائمة الجانبية المشتركة
- لوحة: تصفية نوع/ارتفاع، خريطة إسقاط نسبي للإحداثيات المتاحة، اختيار متعدد، مقارنة، تفاصيل محطة
- قيم الرصد: تُعرض **غير متاح** حتى اعتماد عقد لقطة

### Flutter
- شاشة `ForecastingCenterScreen` من الصفحة الرئيسية
- نفس سياسة عدم اختراع قيم رصد

## ما لم يُنفَّذ (عن قصد / يحتاج موافقة)

| البند | السبب |
|---|---|
| لقطة حرارة/رياح/ضغط لحظية لكل المحطات | يحتاج عقد قراءة معتمد + غالباً صلاحية/`RPC` جديدة دون توسيع غير موافق عليه |
| مصدر خارجي | لم يُزوَّد بعد؛ Adapter موثّق لاحقاً |
| خريطة أساس تجارية | إسقاط نسبي فقط من الإحداثيات الحقيقية |
| SQL / جدول لقطات | **لا تطبيق** دون موافقة |
