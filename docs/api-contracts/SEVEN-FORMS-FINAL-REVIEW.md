|---|---:|---:|---|---|

## 2. مصفوفة صلاحيات دقيقة (مقترح — غير مفعّل)

رموز الرصد = نفس عائلة Access Context الحالية.  
رموز الأعطال = **مقترحة جديدة** ولا تُضاف إلى RPC/جدول الأدوار دون موافقة.

| الدور | create | edit_own_draft | submit | review | approve | return | assign | resolve | close |
|---|---|---|---|---|---|---|---|---|---|
| `observer` | رصد: مرشّح | رصد: مرشّح | رصد: مرشّح | لا | لا | لا | لا | لا | لا |
| `station_head` | لا رصد | لا | لا | رصد: نعم (حالي) | لا | رصد: نعم | أعطال: مقترح | لا* | أعطال: مقترح |
| `station_auditor` | لا | لا | لا | رصد: نعم | لا | رصد: نعم | لا | لا | لا |
| `chief_auditor` | لا | لا | لا | لا** | رصد: نعم | رصد: نعم | لا | لا | لا |
| `aftn_operator` | لا رصد | لا | لا | لا | لا | لا | لا | أعطال اتصالات: مقترح محدود | لا |
| `system_admin` | لا bypass رصد | لا | لا | لا | لا | لا | لا | لا | IT: مقترح حذر |
| `network_director` / `statistics_director` | لا | لا | لا | لا | لا | لا | لا | لا | لا |

\* resolve لرئيس المحطة اختياري تشغيلياً.  
\*\* chief_auditor لا يملك `observation.review` في المصفوفة الحالية؛ يملك approve/return.

**توافق Access Context:** اليوم تُفحص فقط رموز `observation.*` و`users.station.*` و`registrations.*`. أي `fault.*` يتطلب توسيع قائمة الفحص في Access Context **بعد** موافقة أمنية — وإلا تبقى الأعطال خارج البوابات الحالية.

### فصل دورات الحياة

| النطاق | الدورة | لا تُخلط مع |
|---|---|---|
| رصد جوي (agricultural, hourlyclimate, rainfall, soil) | draft → submitted → approved / returned | أعطال |
| أعطال أجهزة | reported → assigned → in_progress → resolved → closed | رصد، IT |
| أعطال اتصالات | نفس دورة الأعطال؛ نطاق معدات اتصالات | faultit |
| بلاغات IT | نفس دورة الأعطال؛ نطاق برمجيات/نشرات/عتاد محطة | faulttelecom كمسار بيانات |

## 5. ما يمكن اعتماده الآن مقابل ما يتطلب موافقة

### يمكن اعتماده اعتماداً على الكتالوج الحالي

- فصل `hourlyclimate` عن `hourly` كاسم نوع وهوية عقد.
- الإبقاء على السبعة **محلية** حتى يوجد عقد خادمي.
- أعداد الحقول وids الحالية كخط أساس للواجهة.
- عدم خلط دورات الأعطال مع دورة اعتماد الرصد.

### يتطلب موافقة المستخدم / التشغيل / الأمن / مالك البيانات

- D1–D7 كاملة (انظر القسم 3).
- تثبيت قوائم choices كمرجع خادمي.
- تحويل text→decimal وحدود رسمية.
- أي رمز `fault.*` أو توسيع Access Context.
- أي جدول/RPC/endpoint.
