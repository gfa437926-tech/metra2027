## قرار D1 — نموذج التخزين

- [ ] **أ)** توسيع `observationType` ليشمل الأنواع الرصدية الأربعة فقط؛ الأعطال في مورد منفصل `/faults`.

- [ ] **ج)** غير ذلك (يُذكر).
