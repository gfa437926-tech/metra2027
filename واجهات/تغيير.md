# تغيير — سجل التغييرات والتقدم في كل جولة

هذا الملف سجل تراكمي إلزامي. يجب تحديثه في **كل جولة عمل** وفي نفس الفرع الذي يحتوي على التغيير البرمجي أو الوثائقي. لا تمسح السجلات السابقة ولا تستبدلها بملخص عام.

## قواعد التسجيل
1. أضف قسماً جديداً في أعلى السجل لكل جولة، مع تاريخ UTC، اسم الفرع، SHA قبل الجولة وبعدها، وPR المرتبط.
2. سجل كل تغيير منفرداً: الملف/المسار، ماذا تغير، لماذا، رقم المهمة، والطلب أو المواصفة التي يستند إليها.
3. افصل بدقة بين:
   - **منجز ومتحقق:** التغيير موجود، وأعيد جلبه/فحصه، والاختبار المطلوب نجح مع رابط/دليل.
   - **منجز دون تحقق:** التغيير موجود لكن لم يثبت الاختبار أو CI.
   - **قيد التنفيذ:** بدأ العمل ولم يكتمل.
   - **غير منجز:** لم ينفذ بعد.
   - **محجوب:** ينتظر قراراً أو بيانات أو صلاحية.
4. لا تسجل «اجتاز الاختبار» بناء على كتابة الاختبار فقط. اذكر الأمر أو CI run والنتيجة الفعلية.
5. لا تعتبر فتح ملف أو إنشاء route أو placeholder إنجازاً وظيفياً كاملاً.
6. سجل التراجعات والأخطاء والتصحيحات أيضاً، ولا تخفِ فشل CI.
7. اربط كل تغيير برقم مهمة من `مهما.md`، وحدّث حالة المهمة هناك في نفس الجولة.
8. لا تسجل الأسرار أو كلمات المرور أو مفاتيح API أو بيانات شخصية حساسة.
9. إذا لم يحدث تغيير في جولة ما، أضف سطراً يوضح ما تم فحصه ولماذا لم يطرأ تغيير.
10. يجب أن يتطابق هذا السجل مع commits وPR في GitHub؛ لا تسجل عملاً لم يُرفع فعلياً باعتباره مرفوعاً.

## قالب الجولة الجديدة
```md
## الجولة N — YYYY-MM-DD HH:MM UTC
- الفرع:
- PR:
- SHA قبل:
- SHA بعد:
- المهمة/المهام:
- الحالة العامة: منجز ومتحقق / منجز دون تحقق / قيد التنفيذ / غير منجز / محجوب

### التغييرات
- [منجز ومتحقق] المسار — وصف التغيير — دليل الاختبار/CI.
- [منجز دون تحقق] المسار — وصف التغيير — سبب عدم التحقق.

### الملفات التي فُحصت
- المسار — نتيجة الفحص.

### القرارات والقيود
- القرار أو القيد وأثره على العمل.

### الخطوة التالية
- رقم المهمة التالية واسمها.
```
