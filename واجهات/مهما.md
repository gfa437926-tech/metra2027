## المهام المفتوحة
1. إجراء اختبارات end-to-end مصادق عليها للويب والهاتف على بيئة اختبار معزولة.
2. ربط كل شاشة تقرير/إدخال بمصدرها الفعلي وتصنيفها API / محلي / Mock.
3. مطابقة جميع RPC والجداول والأعمدة مع migrations المعتمدة دون تطبيق أي تغيير.
4. تثبيت DTOs مشتركة وإضافة contract tests بين Angular وFlutter و.NET.
5. توثيق وتشغيل واجهة R/Climatol المقترحة بعد اعتماد عقدها.
6. توثيق وتشغيل مسار صور السجلات والمدقق بعد اعتماد نموذج الأدلة والتدقيق.
