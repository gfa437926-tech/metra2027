# مهام المشروع المشتركة — METRA 2027

## قواعد العمل

1. قراءة هذا الملف و`تغيير.md` و`README.md` قبل بدء أي جولة.
2. العمل على فرع مستقل وعدم الدمج إلى `main`.
3. عدم تعديل قاعدة البيانات أو سياسات RLS أو تطبيق migrations دون موافقة المستخدم.
4. عدم نسخ الأسرار أو مفاتيح API أو بيانات الاعتماد إلى التقارير أو المحادثات.
5. توثيق التغييرات والاختبارات والنتائج الفعلية، وعدم ادعاء نجاح اختبار لم يُنفذ.
6. احترام اختصاص بقية المساعدين وتجنب تعديل الملفات التي لا تدخل في نطاق المهمة.

## المساعد رقم 7 — الأمن السيبراني

**الفرع:** `security/initial-hardening-audit`

**المهمة:** تدقيق المصادقة والصلاحيات ونطاق المحطات وواجهات API والأسرار والتشفير والسجلات وCORS والاعتماديات وإعدادات النشر.

**النتيجة الأولية:** أُنجزت مراجعة ساكنة للمصدر والإعدادات ذات الصلة. ظهرت ضوابط جيدة في JWT وstation-scoped authorization وauthority-scoped approval وRLS وحماية مفاتيح service-role. توجد بوابات إطلاق مفتوحة تخص جاهزية الإنتاج، rate limiting، security headers/HSTS، حدود حجم الطلبات، CSP وتخزين جلسة المتصفح، وAllowedHosts، ومراجعة سجلات الأحداث.

**إصلاحات آمنة على الفرع:**
- استكمال قواعد تجاهل ملفات الأسرار والمفاتيح المحلية في `.gitignore`.
- تفعيل فحص npm عالي/حرج ضمن Client CI مع استخدام `npm ci`.

**التقرير التفصيلي:** `docs/security/SECURITY-AUDIT-2026-11-11.md`

**القيود:** لم تُجرَ اختبارات على أنظمة حية، ولم تُعدل قاعدة البيانات أو RLS، ولم تُنشر أي خدمة. يجب مراجعة نتائج CI على Draft PR قبل اعتبار إصلاحات الاعتماديات ناجحة.
