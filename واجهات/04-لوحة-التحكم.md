# UI-04 — لوحة التحكم الرئيسية

## الهدف
عرض ملخص عمل المستخدم وروابط الوحدات التي يملك حق الوصول إليها، دون كشف بيانات خارج نطاقه.

## مكونات الصفحة
- ترحيب وبيانات الحساب المختصرة.
- بطاقة المحطة/المحطات المسندة الحالية إن وجدت.
- مؤشرات العمل: سجلات تنتظر الإرسال، سجلات مرسلة، سجلات معادة، مهام مراجعة، بلاغات صيانة، طلبات دعم؛ لا تظهر إلا إذا كانت API توفرها وصلاحية المستخدم تسمح بها.
- آخر الأنشطة مع وقت UTC.
- تنبيهات تشغيلية وروابط مباشرة إلى العنصر.
- اختصارات: الرصد الساعي، الرصد اليومي، المحطات، التقارير، التنبؤ، التدقيق، الصيانة، الإدارة حسب الصلاحيات.

## سلوك البيانات
كل بطاقة مرتبطة بمصدر API وتعريف واضح للفترة والحالة. لا تستخدم أرقاماً تجريبية أو مجموعات وهمية في الإنتاج. إذا لم توجد بيانات تعرض «لا توجد بيانات متاحة» بدلاً من الصفر المضلل.

## الصلاحيات
تختلف البطاقات حسب grants ونطاق المحطة. لا يُستنتج الوصول الشامل من اسم الدور.

## حالات العرض
تحميل كل مجموعة بشكل مستقل، فارغ، خطأ جزئي، بيانات قديمة، ممنوع.

## حالة التنفيذ
Angular route `/` موجود واللوحة جزئية وتعتمد على توافر APIs. يلزم تكملة Flutter parity ومصادر كل مؤشر.
