# تنسيق مساهمات METRA 2027

## الغرض
هذا المجلد سجل تنسيق تراكمي بين المساعدين. يجب أن تبقى القرارات والتغييرات السابقة محفوظة.

## قواعد العمل
1. اقرأ `مهما.md` و`تغيير.md` قبل البدء.
2. أضف تحديثاً مؤرخاً بدلاً من حذف أو إعادة كتابة السجل.
3. اذكر الفرع والملفات المتغيرة والأدلة والاختبارات وحالة التنفيذ.
4. لا تعدل وحدة مساعد آخر دون التنسيق معه.
5. لا تغيّر قاعدة البيانات أو تطبق migrations دون مراجعة وموافقة صريحة.
6. لا تخلط بيانات Mock مع الرصد التشغيلي، ولا تعرضها كأنها بيانات حقيقية.
7. وجود endpoint أو نجاح build لا يثبت التكامل الحي.
8. استخدم فروعاً مستقلة وPR Draft للمراجعة؛ لا تدمج بنفسك.
