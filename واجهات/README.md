## ضوابط ملزمة
1. التوقيت المعروض والمدخل والمخزن في تقارير METRA هو UTC فقط؛ لا تحويل ولا إظهار للتوقيت المحلي.
2. الواجهة لا تمنح الصلاحية. الخادم يتحقق من هوية المستخدم وصلاحياته وتعيينه للمحطة في كل طلب.
3. لا استخدام لقاعدة البيانات أو المستودع القديم، ولا استيراد لمحطاته القديمة.
4. لا تطبيق SQL أو migrations أو RLS أو seeds قبل مراجعة المخطط وموافقة المالك الصريحة.
5. لا بيانات رصد أو إحداثيات أو ارتفاعات أو حدود علمية افتراضية. القيم غير المعتمدة تظهر «غير متاح/غير معتمد».
6. لا تعديل تلقائي للسجلات الأصلية من وحدات الذكاء الاصطناعي أو التجانس.
7. لا دمج إلى main أو نشر دون موافقة صريحة.
8. Angular وFlutter واجهتان مستقلتان وظيفياً مع تكافؤ مسارات العمل، وليس شرطاً تطابق تخطيط الهاتف مع سطح المكتب.

## كيفية قراءة حالة الشاشة
- **موجودة جزئياً:** يوجد route/component أو مسار عمل، لكن لا يعني ذلك اكتمال التصميم والوظائف.
- **هيكل/Placeholder:** الشاشة موجودة شكلياً أو كمسار أولي.
- **مقترحة:** مواصفة مستخلصة من متطلبات المالك ولم يثبت وجود تنفيذ كامل لها.
- **مقيدة بقرار:** لا تستكمل قبل اعتماد قاعدة علمية أو صلاحية أو مصدر بيانات.
