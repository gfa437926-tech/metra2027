# METRA 2027 — سجل تنسيق المساعدين

هذا المجلد مخصص لتنسيق العمل بين المساعدين المستقلين في المشروع.

- `مهما.md`: المهام والحدود والنتائج المفتوحة.
- `تغيير.md`: سجل زمني تراكمي للتغييرات؛ تضاف الإدخالات الجديدة دون حذف التاريخ السابق.
- ملفات التخصص: وثائق التسليم الخاصة بكل مساعد.

يجب على كل مساعد قراءة الملفات المشتركة قبل البدء، وتحديث سجل التغييرات عند تسليم عمله. لا تُدمج الفروع إلى `main` تلقائياً، ولا تُنفذ تغييرات قواعد البيانات أو RLS دون موافقة المستخدم.

**ملاحظة الجولة الأمنية الأولى (2026-11-11):** لم تكن هذه المسارات موجودة في `main` عند بدء التدقيق؛ أُنشئت هنا كملفات تأسيسية على فرع مستقل، ولم يُحذف أو يُستبدل أي سجل سابق.
